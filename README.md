# The Vinyl Room

Application Android native en Kotlin + Jetpack Compose, inspirée du visuel de référence fourni.

## Direction visuelle
- Ambiance de salle d'écoute chaleureuse, bois sombre et éclairage ambré.
- Bibliothèque de vinyles avec pochettes en perspective et album central mis en avant.
- Navigation et commandes de lecture adaptées au format vertical Android.

## État du projet
Prototype d'interface en cours. Les albums et pochettes sont provisoirement des données de démonstration ; la connexion Spotify (OAuth), la synchronisation de bibliothèque et les commandes de lecture restent à intégrer.

## Stack
- Kotlin
- Android Gradle Plugin
- Jetpack Compose

Le projet est destiné à Android uniquement.
